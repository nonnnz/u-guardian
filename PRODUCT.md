# U-Guardian
<!-- impeccable:product-schema 1 -->

## Platform
Web component and Node.js backend. Minimal web demo host; portable to other web applications using an authenticated host transport.

## Users
Thai-speaking crypto beginners who want plain-language answers, wallet explanations and selected monitoring without learning specialist vocabulary first. U-topia and other application operators are potential integrators; no commercial integration is claimed.

## Product Purpose
Sell the agentic companion, represented by a voice-enabled mascot. The website demonstrates embedding rather than competing with the host's financial application.

## Stack
Vanilla JavaScript custom element with Shadow DOM, CSS geometric mascot, Node 24, U-bot web chat adapter, Avalanche RPC/Data API, Tokenomist v5, ElevenLabs STT/TTS. Vercel private encrypted Blob sessions for the public demo; local .env and state for local development.

## Capabilities and Constraints
Three pillars: wallet health and goal-aware explanations; investigation of changes since an acknowledged briefing; user-confirmed watch rules. Multi-step U-bot tool loop with validated allowlist and bounded steps. Token research includes allocation, fundraising, buyback and burn datasets when covered. Voice is push-to-talk with visible errors and text alternative, not continuous listening. No automatic trading. Health does not yet cover approvals or DeFi. No claims of buy/sell timing from tokenomics alone. Demo and live are explicit. Public Vercel monitoring runs while the widget is visible or the host invokes checks; background scheduler, SMS and Web Push are not provisioned. Embedding requires host-owned authentication and provider secrets on the backend. Existing settings and Fuji tools remain accessible at settings.html.

## Brand Commitments
U-Guardian, Thai first, warm ivory/forest/sage, approachable geometric robot mascot with eyes, mouth and hands responding to operational state. Minimal wallet shell; companion first on mobile. Existing identity retained.

## Product Principles
Evidence before advice. Missing data remains unknown. Exact wallet quantities; no invented fiat values. Explicit confirmation before saving a watch. User-controlled voice and playback. Host integration through a documented API boundary.
