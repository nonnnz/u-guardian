02Problem
a_balance_is_not_an_answer

A balance is not an answer.

  • A wallet can show how much you hold. It rarely explains what changed, why it matters to your goal, or what to watch next.
  • A new user may have to piece together wallet activity, token supply, market context, and news across several products.
  • This matters when the same money is intended for a future expense, savings, or everyday use.

03Solution
one_companion_three_jobs

One companion, three jobs.

PillarWhat the user asksWhat Guardian does
Wallet health“Is my wallet too concentrated for a six-month goal?”Reads the public Avalanche wallet and explains holdings, coverage, and concentration in the context of a saved goal.
What changed & monitor“What changed?” / “Alert me if AVAX drops 10%.”Compares the latest observations with a prior briefing; drafts a specific watch for user confirmation.
Advice with real information“What is AVAX, and what should I watch out for?”Uses retrieved project, market, tokenomics, and available headline evidence to explain trade-offs and uncertainty.

Product idea: the mascot is the agent interface. Text, voice, status animations, sources, and watch confirmations are all in one conversation.

Built with

Node.js backend; a single-page JavaScript web UI; Vercel and private session storage for the hosted MVP. The server validates U-bot's JSON tool request against an allowlist and executes the selected function. The model does not run arbitrary generated code.

Why this matters

Wallet data personalizes the answer. Tokenomist adds supply and project evidence. Public market and news sources fill gaps the sponsor APIs do not cover. ElevenLabs makes the agent accessible by voice. Debug shows each tool choice, result, and failure.

06Impact & business model
inside_an_existing_app

Make crypto easier to understand inside an existing app.

Value to users

Fewer tabs to interpret a wallet; clearer risk context tied to a personal goal; user-chosen alerts with an explanation of what triggered them.

Value to a platform

A companion that can sit beside an existing wallet experience and make its data more useful without asking the platform to replace its wallet.

Proposed model · hypothesis

B2B licensing / white-label companion for wallet and financial apps, with a platform fee and usage-based pricing for agent and voice calls. Not launched pricing.

Pilot measures · to measure

Time to understand a wallet change; % of users who correctly understand an alert; watch activation and retention; source-detail views; voice use; provider cost per useful answer. Not claimed results.
