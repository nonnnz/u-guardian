# U-Guardian POC design

Operate surface: personal financial field journal. Calm daylight workspace for reviewing a specific reserve goal, with an adjacent conversation. The approved functional brief takes precedence over a separate visual approval round.

Grounded concepts considered: financial statement, savings envelope, household planner, navigation console, personal ledger, financial field journal, service desk. The sixth direction follows the local concept assignment; the remote design catalog was unavailable.

Warm paper #f6f6f0, deep forest #203d34, sage #eaf0e3, terracotta for evidence requiring attention. Serif editorial headline contrasts with compact Thai-capable interface text. Thin separators organize holdings and events. Consistent authored outline SVG icons. Actual evidence and reserve progress provide the visual structure; no decorative charts.

Desktop: slim fixed navigation, goal-centered workspace, sticky conversation. Mobile: compact navigation, stacked wallet and assistant, full-width review dialogs. Color is accompanied by text. Reduced-motion support, visible focus, native dialogs, associated form labels. Provider credentials never appear in UI state responses.

Live extension: an explicit Wallet data selector sits above the reserve. A source panel carries network, public address, block, timestamp and coverage warnings. Tokenomist fixtures disappear in Live mode. Exact units remain in the holdings/evidence; the large reserve display abbreviates long decimals with an approximation marker. Fuji review is a separate explicit flow with full addresses, amount and gas, followed by wallet signing and receipt status.

Goal-risk extension: the goal assessment appears before holdings, keeping the reason for attention ahead of the asset inventory. Reasons and coverage limitations remain readable text, with limitations in an expandable evidence section. Live supply evidence extends the horizon section with refresh, event and emission details, and source coverage. Manual token identity matching uses a labeled dialog and an explicit chain/contract confirmation; matching symbols alone do not establish identity.

Phone extension: the voice-alert section shows setup status, review actions and call history. The setup dialog keeps destination consent, connected outbound number, agent configuration, quiet hours and call limits together. Saving settings is distinct from placing a call. A separate review dialog presents the real test-call action and its confirmation. These surfaces retain the existing warm ivory, forest and sage palette, compact Thai interface text and full-width mobile dialog treatment.

Readability and accessibility extension: muted supporting text uses #59685f. Holdings quantities, prices and values stay on one line; address and contract metadata may wrap anywhere. Preserve exact numeric evidence without breaking digits across lines. The chat composer has an associated accessible label, icon-only reserve and supply actions have descriptive accessible names, and the phone setup, test-call review and identity-matching dialogs are named by their headings. Status and history updates use status or polite live regions where implemented.
